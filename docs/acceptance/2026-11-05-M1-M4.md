### 5.2 未实现（超出本轮范围）

| # | 项 | 说明 |

| 1 | 换句检验（transfer） | 后端有，前端未接候选检索；计划 M2 提到但本轮优先做了三类反馈 |

### 5.3 设计取舍（不是缺陷）

| 项 | 说明 |
| --- | --- |
| 必须先交卷才能确认句子 | 合理约束（没交卷不知道你卡在哪题），UI 已提示 |
| `next`/`finish` 需带 `stepId` | 防过期响应（计划 §5），前端已自动带 |
| 复习动作需 `actionId` | 幂等去重，重复提交不重复计时 |
| 只有句级时间轴 | 底座 `mfa_available: false`，不伪装词级精度 |
| 卡点按会话隔离 | 换浏览器/清 sessionStorage 后看不到旧卡点，属设计行为 |
| 跳过不记完成 | 跳过 ≠ 听懂（计划 T12 硬要求） |

### 5.4 本轮修的 6 个真实缺陷

1. `next` 动作在 `currentStep.action`，前端读 `step.action` → 显示「已更新」
2. 句子时间字段 `startSeconds`/`endSeconds`，前端用 `startSec` → currentTime 抛错
3. 复习 `start`/`skip` 必须带 `actionId`，缺了报 422
4. 新建复习是 `ready`，`skip`/`complete` 需要 `active`，需先 `start`
5. `startReview` 未调 `save()` → 刷新后无法恢复复习
6. Playwright Sync API 重复 `with` → 单独跑通过、全量跑失败
