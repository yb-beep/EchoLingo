# CET 听力接口 · 权威契约

> **这是唯一权威定义。** 后端、前端、Mock、测试构造器都必须遵守本文。
>
> 更新：2026-11-05｜旧版实际映射保留在 `api-contract-mapping.md`
>
> 为什么需要这份文档：验收报告 C04 指出契约测试大量失败，根因不是缺 AI key，
> 而是**四端各说各话**——`complete/succeeded`、`finish` 包装、
> `start/playback_start`、`speed/playbackRate` 两套并存。
>
> **实测证据**：用受控模型（`scripts/cet/run_contract_controlled.py`，在 `cet_ai._call`
> 边界注入固定响应，保留真实路由/数据库/状态机）跑完整契约，结果与无 key 环境
> **完全一致**（39 failed / 33 passed）。所以「需要 key 才能过」的分类不成立。

---

## 1. 通用约定

| 项 | 规定 |
| --- | --- |
| 时间轴字段 | 绝对秒，命名 `startSec` / `endSec`（**不是** `startSeconds`） |
| 时长/预算 | 毫秒，命名 `*Ms`（`effectiveMs`、`budgetMs`、`activeMs`） |
| 材料身份 | `materialId` + `materialVersion`，**不得用文件路径** |
| ID 生成 | `attemptId` / `markId` / `practiceId` / `reviewId` 由**服务端生成** |
| 幂等键 | 客户端传 `actionId` / `eventId` / `requestId`，服务端据此去重 |
| 错误格式 | `{"detail": {"code": "...", "message": "...", ...上下文}}` |
| 开发样例 | 带 `developmentFixture: true` |

---

## 2. 播放事件（唯一写法）

`POST /api/cet/practices/{practiceId}/events`

**事件类型只有这三种**：

| 类型 | 含义 |
| --- | --- |
| `playback_start` | 开始播放 |
| `playback_end` | 播放结束（携带计时） |
| `playback_interrupt` | 被打断（切页、后台） |

**其他类型一律 422 拒绝**（如 `pause`、短名 `start`/`end`）。

```json
{
  "eventId": "ev-xxx",
  "type": "playback_end",
  "stepId": "<当前步骤>",
  "materialVersion": "<材料版本>",
  "audioTime": 38.5,
  "speed": 1.0,
  "activeMs": 4000
}
```

**计数字段是 `activeMs`**（不是 `playedMs`）。响应顶层带 `effectiveMs` 与 `status`。

---

## 3. 练习对象（Practice）

**`step` 与 `currentStep` 是同一对象**，两个键都返回（`step` 为契约名）。

```json
{
  "practiceId": "practice-xxx",
  "status": "active",
  "revision": 3,
  "stepCount": 5,
  "step": {
    "stepId": "abc123",
    "id": "abc123",
    "sequence": 1,
    "action": "slow",
    "source": "local",
    "playback": { "startSec": 36.77, "endSec": 41.41, "speed": 0.75 },
    "playRange": { "startSeconds": 36.77, "endSeconds": 41.41 },
    "speed": 0.75,
    "textVisible": true,
    "showText": true,
    "feedback": "sound",
    "data": {}
  },
  "currentStep": { "…同 step…" },
  "latestFeedback": "sound",
  "effectiveMs": 4000
}
```

- **动作枚举**：`replay` / `slow` / `chunk` / `explain` / `transfer` / `finish`
- **状态枚举**：`active` / `complete`（**不是** `succeeded`）

## 4. 交卷（Attempt）

`POST /api/cet/attempts`

```json
{
  "materialId": "cet6-202512-conv2",
  "materialVersion": "sha256-...",
  "listeningSessionId": "session-abc",
  "answers": [{ "questionId": "cet-q05", "choice": 1 }]
}
```

- `choice` 是 **0-based 选项索引**
- **幂等**：同一 `materialId` + 非空 `listeningSessionId` 只能有一条记录；
  空 session 不参与唯一约束（旧客户端只传 `attemptId` 时保留多份）

响应 `results[]` 每条含 `questionId` / `number` / `choice` / `answer` / `correct` /
`answerSource` / `evidenceRef` / `explanation`

- **未作答**：`choice: null`、`correct: null`（**不是** `false`），计入 `unansweredCount`
- **未知答案**：`answer: null`、`correct: null`，计入 `unknownCount`

`GET /api/cet/attempts/{attemptId}` 可取回同一结构（刷新恢复用）。

---

## 5. 复习（Review）

`POST /api/cet/reviews` 请求 `{ "maxItems": 3 }`

| 契约名 | 旧名 | 说明 |
| --- | --- | --- |
| `reviewId` | `id` | 会话 ID |
| `items` | `entries` | 条目列表 |
| `count` | — | 条目数 |

条目字段：`entryId`/`id`、`itemId`、`order`/`position`、`status`、`practiceId`、`item`

- **条目状态**：`current` / `pending` / `done` / `skipped`
- **会话状态**：`ready` / `active` / `paused` / `complete`

`POST /api/cet/reviews/{reviewId}/actions`

```json
{ "action": "skip", "actionId": "rv-xxx", "practiceId": "practice-xxx" }
```

- **`actionId` 必填**（幂等去重）
- 动作：`start` / `pause` / `resume` / `skip` / `complete` / `replace` / `finish`
- `skip` **不记为完成**（跳过 ≠ 听懂）

---

## 6. 标记（Mark）

`POST /api/cet/marks`

```json
{
  "materialId": "cet6-202512-conv2",
  "materialVersion": "sha256-...",
  "listeningSessionId": "session-abc",
  "pressedAtSec": 36.9
}
```

- `pressedAtSec` 是**按下空格时的媒体时间**（不是系统时钟）
- `markId` 由服务端生成；响应含 `suggestedSentenceId`（吸附建议）

`PATCH /api/cet/marks/{markId}` 请求 `{ "confirmedSentenceId": "v2-2181-11" }`

**前置条件**：必须先交卷（否则 `409 ATTEMPT_REQUIRED`）。

---

## 7. 本地动作

`POST /api/cet/practices/{practiceId}/local`

```json
{ "action": "slow", "actionId": "act-xxx", "stepId": "...", "materialVersion": "..." }
```

- **`actionId` 必填**
- 动作：`replay` / `slow` / `chunk` / `explain`

---

## 8. AI 请求状态与取消

`GET /api/cet/practices/{practiceId}/ai-status`

```json
{
  "practiceId": "practice-xxx",
  "status": "pending",
  "aiRequest": { "requestId": "req-xxx", "status": "pending", "action": "explain", "createdAt": "..." }
}
```

状态：`idle` / `pending` / `succeeded` / `failed` / `cancelled` / `stale`

`POST /api/cet/practices/{practiceId}/ai-cancel` 请求 `{ "requestId": "req-xxx" }`

- **`requestId` 参与判断**：只取消匹配当前 active 的请求，不误伤新请求
- 不传时只取消当前 active 请求
- 取消后**保留请求记录与终态**，`aiRequest` 不为 null
- **迟到响应不能把 `cancelled` 覆盖成 `stale`**
- 语义区分：被新动作取代 → `stale`；用户主动取消 → `cancelled`

## 9. 材料

`GET /api/cet/materials` → `{ "items": [...], "count": N }`

`GET /api/cet/materials/{materialId}?version=...`

```json
{
  "material": {
    "materialId": "cet6-202512-conv2",
    "materialVersion": "sha256-...",
    "title": "...",
    "level": "cet6",
    "audioUrl": "/output/v2_assets/2181/cet6-202512-conv2.mp3",
    "durationSec": 105.486,
    "sentenceCount": 32,
    "questionCount": 5
  },
  "sentences": [
    {
      "sentenceId": "v2-2181-0",
      "index": 0,
      "startSec": 0.01,
      "endSec": 3.49,
      "text": "...",
      "materialId": "...",
      "materialVersion": "..."
    }
  ]
}
```

- **`version` 不符必须 409 拒绝**（不能返回 200）
- 句子身份用 `sentenceId`（形如 `v2-2181-0`），**测试不得假设 `s01` 形式**

`GET /api/cet/materials/{materialId}/questions` → `{ "items": [...], "count": N }`

**交卷前硬约束**：不返回 `answer` / `correct` / `evidenceRef` / `explanation` / `answerSource`。

## 10. 错误码

| 码 | HTTP | 含义 |
| --- | --- | --- |
| `MATERIAL_NOT_FOUND` | 404 | 材料不存在 |
| `MATERIAL_VERSION_CHANGED` | 409 | 版本不符 |
| `ATTEMPT_REQUIRED` | 409 | 未交卷 |
| `STALE_RESPONSE` | 409 | 步骤/版本过期 |
| `PRACTICE_COMPLETE` | 409 | 练习已结束 |
| `INVALID_EVENT` | 422 | 事件类型非法 |
| `INVALID_LOCAL_ACTION` | 422 | 本地动作非法或缺 actionId |
| `INVALID_REVIEW_ACTION` | 422 | 复习动作非法或缺 actionId |
| `AI_NOT_CONFIGURED` | 503 | 模型未配置（**环境问题，非缺陷**） |

## 11. 已知未统一项（诚实列出）

| 项 | 现状 |
| --- | --- |
| 旧字段仍在返回 | `startSeconds`/`endSeconds`、`showText`、`playRange`、`entries`、`id`（向后兼容），新代码应用契约名 |
| Mock 与真实后端复习动作集 | Mock 含 `switch`/`done`/`tick`，真实后端用 `skip`/`complete` |
| 慢响应注入 | 真实路由不识别 `scenario=slow`（Mock 专用），测试应用传输层延迟 |
