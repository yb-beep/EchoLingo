### 9.3 过程中修的两个真实缺陷

标记永远收不到。
→ 进入练习模式时主动 `blur()`，并放宽按钮判断（cet 自己的按钮不拦）。

### 10.5 本轮修的 6 个真实缺陷

1. `next` 返回动作在 `currentStep.action`，前端读 `step.action` → 显示「已更新」
2. 句子时间字段是 `startSeconds`/`endSeconds`，前端用 `startSec` → currentTime 赋值抛错
3. 复习 `start`/`skip` 必须传 `actionId`（后端幂等去重），缺了报 422
4. 新建复习是 `ready`，`skip`/`complete` 需要 `active`，需先 `start`
5. `startReview` 未调 `save()` → 刷新后无法恢复复习
6. Playwright Sync API 重复 `with` → 单独跑通过、全量跑失败

另清理 3 条孤儿复习条目（引用已删除练习），这是历史测试残留导致的 500。
