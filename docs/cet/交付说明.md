## 一、这是什么

在 EchoLingo 上做的**四六级听力训练**。核心是「**卡点**」：

> 听的时候没跟上的地方按一下空格留个标记 → 交卷后回到那个位置确认 → 按「没听清」或「不懂意思」得到不同帮助 → 隐藏提示原速回听 → 保存进今日复习

区别于普通播放器：**它记得你卡在哪，并围绕那个位置组织后续练习。**

## 三、三分钟操作单

1. 打开六级材料页，点右上「**开始卡点练习**」
2. 点播放，听 2 秒后按 **空格** → 下方出现卡点（**音频不会停**）
3. 右侧选几道题 → 点「**交卷**」
4. 看判题结果与原声证据（带时间戳）→ 点卡点行的「**确认这句**」
5. 点「**开始带练**」→ 点「**没听清**」（会慢放）
6. 点「**今日复习**」→ 试「跳过」「暂停」
7. **刷新页面** → 卡点与复习都还在

## 十、出问题怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `run.sh` 报「材料缺失」 | 音频不入库 | 按第四节获取 |
| 页面无卡点控件 | 当前课程不是四六级材料 | 只在 `2181`/`2182` 有 |
| 「确认这句」点了报错 | 还没交卷 | 先交卷 |
| 「不懂意思」提示模型未配置 | 没配 AI 密钥 | 属正常降级，回听/慢放仍可用 |
| 复习提示「没有待复习卡点」 | 还没保存过练习 | 先走完一轮带练并点「保存本轮」 |
| 刷新后卡点没了 | 换了浏览器或清了 sessionStorage | 卡点按会话隔离，属设计行为 |
