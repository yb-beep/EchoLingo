证据：[串材料页面](./evidence/aa064cc-independent/cross-material.txt)、[截图](./evidence/aa064cc-independent/cross-material.png)、[刷新前正文](./evidence/aa064cc-independent/explain-success.txt)、[刷新后](./evidence/aa064cc-independent/explain-after-reload.txt)。

## R2 · P1 · HTTP 409 拒绝了旧步骤，但旧反馈仍污染数据库

**证据：真实 API 与数据库复现。**

最短复现：新建练习并记下 stepId → 以该步骤发送 sound，成功进入新步骤 → 再以旧 stepId 发送 meaning。第二次返回 `409 STALE_RESPONSE`，但 latestFeedback 从 sound 变成 meaning，feedbackHistory 从 1 条变成 2 条。

根因：`backend/webapp/services/cet_service.py:1293` 在验证步骤、版本、练习状态前调用 `_persist_feedback()`；后者在 1276 行独立 commit。1306–1310 行拒绝请求时已经无法撤销。正常请求“能落库”并不足够。

证据：[API 复现数据](./evidence/aa064cc-independent/api-repro.json)、[数据库事件](./evidence/aa064cc-independent/db-evidence.json)。

返修要求：先验证归属、当前步骤、版本、状态与幂等键，再在受保护的事务中记录反馈、推进状态。被拒绝的请求必须不改变反馈、历史、revision、计时或完成状态。补旧步骤、旧版本、已完成练习、重复 requestId、并发反馈的回归。模型失败可保留合法用户反馈，但前端必须同步后端实际状态。

## R3 · P1 · 换句按钮不提交，页面却声称“已提交”

**证据：受控生成 + 真实 API/前端/数据库。**

最短复现：可用候选的练习 → “听懂了” → 返回符合生成入口要求的受控选项 → 页面出现 `A. [object Object]`、`B. [object Object]` → 点击 A，提示“换句作答已提交（详见后端记录）”。

- `frontend/static/cet-listening.js:607–609` 将归一化后的选项对象直接拼成字符串。点击事件只有 flashHint，没有 API 请求。
- 本轮练习 `practice-7fd8dbbd0c53` 的事件中没有 `transfer_answer`，也没有真正的答案提交。
- “无候选提示已做”也不完整：后端 `cet_service.py:1405` 将无候选步骤设成 finish；前端只在 action===transfer 时调用 renderTransfer，无候选提示分支未接上。此项为源码判定。

证据：[点击后的页面](./evidence/aa064cc-independent/transfer-fake-submit.txt)、[截图](./evidence/aa064cc-independent/transfer-fake-submit.png)、[事件列表](./evidence/aa064cc-independent/db-evidence.json)。

返修要求：按接口展示选项 label/text；切到候选真实音频和范围；答题发送真实事件并等待确认；提交失败不得显示成功。完成状态以服务端结果为准，刷新仍能还原。暂无候选时明确“未检验”，不记掌握。未接通前应移除假提交按钮，不能以成功文案占位。

## R4 · P1 · “已暂停”与音频播放状态不一致

**证据：真实浏览器 + 媒体属性。**

最短复现：今日复习 → 当前条目回听 → 音频正在播放时点复习面板“暂停”。页面显示“已暂停”并出现“继续复习”，但播放器 `paused=false`，currentTime 约 30.55 秒，声音继续至原回听范围结束。

`frontend/static/cet-listening.js:909–918` 只更新后端状态与面板，不停止现有回放。回听按钮也没有按条目材料切换音源。`sendEvent():691–704` 将播放事件写给 S.practice，而不是复习当前条目的 practiceId，还把音频时刻夹入当前步骤范围，可能掩盖播错片段；这些计时归属问题本轮只作源码风险判定。

证据：[暂停时媒体属性](./evidence/aa064cc-independent/review-paused.json)、[截图](./evidence/aa064cc-independent/review-paused.png)。

返修要求：暂停、跳过、结束均清理旧回放；继续恢复同一复习会话。复习音源、时间范围、计时事件均绑定当前条目。必须测复习条目不属于当前页面材料的情况，不能只验证按钮文字。
