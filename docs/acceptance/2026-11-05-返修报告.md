## 1. 逐项修复与证据

### F06 · 未作答被显示成选了 A ✅ 已修

**根因**（报告判断正确）：
```python
"choice": ("ABCDE".index(letter) if letter in "ABCDE" else None)
# 未作答时 letter = ''，而 '' in 'ABCDE' 为 True，.index('') = 0 → 显示成 A
```

**修复**：
```python
"choice": ("ABCDE".index(letter) if letter and letter in "ABCDE" else None),
"answer": ("ABCDE".index(str(correct_letter))
           if correct_letter and str(correct_letter) in "ABCDE" else None),
```

**顺带修正**（报告 F06 修复标准要求）：未作答不再判 `correct=False`（当错答），
改为 `status="unanswered", correct=null`，并新增 `unansweredCount`。

**实测**（只答第 1 题）：
```
Q5 choice=1      answer=1      correct=True
Q6 choice=None   answer=1      correct=None
Q7 choice=None   answer=3      correct=None
Q8 choice=None   answer=2      correct=None
Q9 choice=None   answer=None   correct=None
unansweredCount=4
```
**浏览器验证**：判题区显示 `['A', '-', '-', '-', '-']`，不再出现四个假 A。

### F02 · 复习回听无效、暂停缺继续入口 ✅ 已修

**根因 1**（报告判断正确）：字段拼写 `startSecondsonds` / `endSecondsonds`。
**根因 2**（报告补充正确）：`!startSeconds` 会把合法起点 0 误排除。
**根因 3**：控制区固定只渲染「暂停」，从不给「继续复习」。

**修复**：
- 新增 `replayRange(start, end)` 统一管理回放守卫，切条目时先 `stopActiveReplay()`
- 起点用 `typeof === 'number'` 判断，允许 0
- 控制区按后端 `status` 决定给「暂停」还是「继续复习」
- 状态文案显示「已暂停 / 进行中 / 已结束」

**实测**：
```
暂停后状态：'已暂停 · 剩余约 10 分钟 · 第 1 处'
出现「继续复习」按钮：True
```

### F03 · 刷新只恢复标记，不恢复交卷与带练 ✅ 已修

**根因**（报告判断正确）：`save()` 存了 `attemptId`/`practiceId`，`restore()` 从未读取；
且用 `sessionStorage`，关标签即丢。

**修复**：
- 改用 `localStorage`（关标签重开也能找回）
- `restore()` 补读交卷结果（新增 `GET /api/cet/attempts/{id}`）与带练状态
- `startPractice()` 补调 `save()`（这是漏存 practiceId 的直接原因）

**实测**：
```
刷新前：已交卷 · 得分 0，带练面板可见
刷新后：已交卷 · 得分 0，带练面板可见=True
```

### F04 · 用户反馈未进入训练记录 ✅ 已修

**根因**（报告判断正确，共三处）：
1. `next_practice_step()` 只用 `feedback` 选动作，**从不落库**
2. 前端**从不发 `/events`**，有效用时永远 0
3. AI 失败时练习停在「有 pending 请求」状态，后续事件被判 `STALE_RESPONSE`

**修复**：
- 新增 `_persist_feedback()`：幂等写入 `cet_practice_events` + 更新 `latest_feedback`
- 前端接 `playback_start` / `playback_end` / `playback_interrupt` / `visibility` 事件，
  时间夹到当前步骤 `playRange` 内（否则后端 422 `PLAYBACK_OUT_OF_RANGE`）
- AI 失败时清空 `ai_request_id` 并回滚状态，让练习可继续
- 503 响应带回当前练习状态（反馈已落库，不该丢状态）

**实测**：
```
反馈 sound  → latestFeedback=sound,   feedbackHistory=1
反馈 meaning → latestFeedback=meaning, feedbackHistory=2（503 也带状态）
事件上报 200 → effectiveMs 从 0 累加到 2000ms
```

- 失败才显示错误

**实测**：无 key 时明确降级「模型尚未配置；仍可使用回听、慢放、原文和保存。」
**未验证**：有 key 时的正文渲染。**这需要你提供 `AI_API_KEY`**（第 6 节）。
