## 通用约定

| 约定 | 内容 |
| --- | --- |
| 时间轴 | 原音频**绝对秒数**，字段名以 `Sec` 结尾 |
| 预算与用时 | **毫秒**，字段名以 `Ms` 结尾 |
| 材料身份 | `materialId` + `materialVersion`，**不用文件路径** |
| 开发样例标识 | 所有 Mock 响应带 `developmentFixture: true` |
| 错误形状 | 业务错误 `{error, error_info}`；请求体解析错误 `{detail}`。解析用 `detail \|\| error_info \|\| error` |
| 反馈值 | `sound`（没听清）/ `meaning`（不懂意思）/ `heard`（自评听懂） |
| 带练动作 | `replay` / `slow` / `chunk` / `explain` / `transfer` / `finish` |
| 练习状态 | `active` / `complete` |
| 复习条目状态 | `pending` / `current` / `done` / `skipped` |
| 复习会话状态 | `ready` / `active` / `paused` / `complete` |
