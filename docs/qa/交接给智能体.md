## 一、项目是什么

**给大学生练四六级听力**。核心创新是「**卡点**」这个概念：

> 听的时候，没跟上的地方按一下空格留个标记；
> 交卷后回到那个位置，确认到底哪句没听懂；
> 然后按「没听清」还是「不懂意思」得到不同的帮助；
> 最后隐藏文字、原速回听，验证是不是真听懂了。

区别于普通播放器：**它记得你卡在哪，并围绕那个位置组织后续练习。**

底座是开源项目 [EchoLingo](https://github.com/shine11224/EchoLingo)（本地优先的英语学习工具），我们在它上面改造。

## 六、接口怎么用（关键约束，别踩坑）

### 完整文档
- `docs/qa/接口规格.md` — 29 个接口，每个字段的类型/可空性/示例
- `docs/qa/实现前必读-契约易漏点.md` — **13 个容易漏的点，建议先读这个**

### 必须知道的 6 个坑

**1. ID 由服务端生成**
`markId`、`practiceId`、`attemptId`、`reviewId` 都不需要前端传，服务端返回。

**2. 必须先交卷才能确认句子**
```
PATCH /api/cet/marks/{id}  → 409 ATTEMPT_REQUIRED
```
这是合理的产品约束（没交卷不知道你卡在哪题）。

**3. next/finish 必须带 stepId + materialVersion**
```
POST /api/cet/practices/{id}/next
{ "feedback": "sound", "stepId": "<当前步骤>", "materialVersion": "<材料版本>" }
```
不带会返回 `409 STALE_RESPONSE`。这是防「过期响应覆盖当前状态」的机制。

**4. 交卷前不返回答案，也不返回 answerSource**
`answerSource` 会暴露「这题有没有可靠答案」，属于间接泄露。

**5. 字段名是契约规定的，不要另起**
```
materialId / materialVersion / durationSec / pressedAtSec / choice / correct
```
完整清单见 `docs/qa/接口规格.md`。

**6. 未知答案判 null，不要当答错**
第 9 题是故意无答案的：`answer: null, correct: null`。前端应显示「参考答案未知」，不能判对错。

### 字段速查（材料对象）

```json
{
  "materialId": "cet6-202512-conv2",
  "materialVersion": "sha256-...",
  "title": "2025年12月六级第一套 · Conversation Two",
```

## 八、设计上要遵守的原则

这些是任务书规定的，也是评委可能问的：

1. **交卷前绝不泄露答案** —— 包括答案、证据句、解释、answerSource
2. **未知答案保留未知** —— 不推断、不填充、不判对错
3. **原始按键时间与确认句子分开存** —— 用户可能按偏，也可能系统吸偏，两者都要留
4. **跳过 ≠ 听懂** —— 复习时跳过某条，它必须留在「待练」而不是「已完成」
5. **等待和暂停不计学习时长** —— 否则时长统计失真
6. **一个播放源** —— 切页面/切句子时必须停掉旧音频
