1. **数据正确**：升级不丢记录或答案；正常库与历史重复库，两种 ID 入口均保证非空会话幂等；空会话不同 ID 保留独立作答；历史冲突不任取一条。
2. **定位可用**：播放时空格立即留标记且音频不停；回溯参数和实际倍速进入定位；用户可先回听候选、调整，再确认；原按键时间和确认句身份都保留。程序覆盖不是人工听检准确率。
3. **带练可用**：没听清立即回听/慢放；不懂意思显示真实接口返回的解释；模型慢/失败时本地操作与保存可用；完成态、过期回包、跨材料、刷新和关标签恢复正确。
4. **换句可用**：按既定流程隐藏原文、恢复原速；有候选时播放正确材料，展示合法题目并真正提交作答；无候选明确“未检验”，不能当通过。
5. **复习可用**：最多三处；暂停确实停声、继续可用；跳过不记完成；计时排除后台/暂停/AI 等待；替换/结束/跨材料音源与刷新恢复真实可用。
6. **可重复交付**：新库无硬编码 lesson ID；启动能确认实际服务和数据目录；后台任务也使用隔离库；音频哈希有效；标记颜色体现在实际时间线。
7. **验证可信**：真实服务使用合法受控模型走成功、慢响应、失败、取消；mock 单列。修复前置后必须继续跑后续断言。整套失败必须处理或明确证明测试不适用并提供等价有效验证，不能删断言/永真断言/批量 xfail。
