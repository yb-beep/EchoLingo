### P1-3 收藏自动回流「我的收藏」 ✅

**根因**（已在源码核对）：工作区「☆ 加入生词」走 `POST /api/v2/lessons/{id}/word`，只写 `v2_lesson_words`（本课词集）；
而首页「我的收藏 · 词汇收藏」读 `GET /vocab-log`（`word_review_items` 表）。两条链不连通 → 收藏 10 个词，我的收藏显示「暂无词汇」。

**改法**：CET 模式下 `toggleWordSave()` 新增分支成功后调用 `autoActivateFavoriteWord()`，
复用**已有**接口，不新增后端：

```http
POST /api/vocab-review/activate
Content-Type: application/json

{"word": "<归一化词>", "source": "listening", "lesson_id": <当前 lesson id>, "meaning": "<释义，有就给>"}
```

**给包4 对齐的 payload 约定**（主代理已确认幂等）：
- `source` 固定 `"listening"`（`backend/db.py:1040 activate_word_review` 的合法值集合里；传 `lookup`/`practice` 会 400）
- 幂等由后端保证：`INSERT ... ON CONFLICT(word) DO UPDATE`，`count = CASE WHEN words.count < 1 THEN 1 ELSE words.count END`
- 所以包4 首页加载时再补调一次**不会重复累加**

**原句关联**：不需要额外接口。`/word` 那条路已写 `v2_lesson_words.sentence` 并调 `db.add_context`；
即使 `contexts` 为空，`db.get_review_words()` 也会回填 `v2_lesson_words` 里的真实课程句（`backend/db.py:955-971`）。

**收藏面板按钮改状态标签**：CET 下 `renderReadingSavedItems()` 输出
`<span class="review-book-state">✓ 已收藏</span>` / `<span>收藏后进入「我的收藏」</span>`，不再给每个词一个「加入复习本」按钮。
通用模式保留原按钮与原行为（原版没有自动回流，不能让用户失去这个操作）。

**失败不打断收藏**：`autoActivateFavoriteWord()` 内 catch 静默 —— 收藏是主操作，回流是附加收益。

```js
function cetBillableFetch(opType, url, options) {
  if (window.eltCredits && typeof window.eltCredits.billableFetch === 'function') {
    return window.eltCredits.billableFetch(opType, url, options);
  }
  return fetch(url, options);   // 没有计费层就普通 fetch，功能不丢
}
```
3 处调用点（`lesson_chat` ×2、`selection_translation` ×1）全部改走守卫，全模板只剩守卫内部 1 处 `eltCredits.billableFetch`。
