## 必须返修（固定范围，不重开智能体开发）

### BASE-01 / P1：手动归类会清掉素材类别

`backend/webapp/services/cet_materials.py:475–495` 删除两类标签，却只重建本次请求包含的字段。首页只提交 level 的实际路径触发。

真实浏览器：六级/样例材料 → 材料管理 → 手动归类 → 仍填六级 → 确定。材料立即变成“六级/未标注”，样例类别丢失。API 反方向只改 category 也会把级别变成 unspecified。

修复：PATCH 未传字段必须保留，明确清空才删除。覆盖改级别、改类别、改标题、归档四种互不串改的场景。

### BASE-02 / P1：JSON 损坏条目静默丢弃

`cet_import.py:197–206` 预先过滤非对象条目。输入 `[合法句1,"BROKEN",null,合法句2]` 返回 200、errors=[]，只落两句。应返回逐条错误并拒绝整份导入，保留原始条目位置。不要把过滤后的长度当全部成功。

### BASE-03 / P2：导入异常与并发重复未处理完整

`cet_import.py:725–741,778–788` 的查重与创建非原子。同标题、同真实音频的两并发请求都 duplicate=false，生成两份材料。屏障仅控制查重后的交错，未伪造业务返回。应保证幂等或明确串行化。

坏字节文件 `bad.mp3` 返回纯文本 500 Internal Server Error，而非结构化格式错误。上传调用在保护范围外，路由仅捕获 ImportValidationError。修为可理解的校验错误，验证无假卡片和残留暂存。

### BASE-04 / P1：启动检查可能删库，停止脚本可能停错实例

- `run.sh --check --fresh --data-dir <临时库>` 删除了真实构造的 sentinel 库，却报检查通过。只检查模式应无数据库删除副作用。
- 同库服务复用判断在删库之前，允许复用活服务后再删除 DB/WAL/SHM：此分支为代码确认，未对真实在用库执行。
- stop 脚本共用 server.pid，未核对其端口。对临时实例 A 执行 PORT=A stop，实际杀了 PID 文件中的 B，A 仍活着，退出码 0。

修复：检查与修改分离；清库前验证所有权及停服状态；PID/端口/数据库按实例绑定，停止前核验身份，不能依靠一个共享 PID 文件。全部使用临时进程回归。

### BASE-05 / P1：底座没有真实的队友模块关闭机制

`workspace.html:1848–1849` 无条件加载卡点资产。实际新导入的无题材料仍出现卡点时间线、开始卡点练习、今日复习、未交卷和交卷按钮。文档所谓关闭是测试用 route.abort() 拦资产，不能代表可交付的关闭模式。

修复：集中配置控制挂载，底座独立运行默认不加载未接入模块；真正接入时开启。只验开关、挂载、事件和快捷键边界，不重写队友算法。验收关闭必须用正式配置，不能靠浏览器拦请求。

### BASE-06 / P1：功能收束未覆盖动态收藏页面

进入“我的收藏”加载后仍有 GRE、雅思、考研、托福标签按钮、“全部造句情况”筛选和“情景造句练习”按钮；这是用户可见实测，不是隐藏 JS 字符串误报。句子收藏也保留句式练习筛选，学习页仍叫“阅读”“加入精读”。

首页还真实请求 `/api/v2/lessons/baidu-pan/capability`；`index.html:8855` 的无条件 initBaiduPanCard 绕过前面的模式判断。

修复：集中模式规则覆盖动态渲染、筛选、旧链接和初始化请求；保留词句收藏能力及数据，退出无关训练入口，不仅换静态标题。材料页、收藏页、设置页逐页实际操作复查。
