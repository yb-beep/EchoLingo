### 9.3 过程中修的两个真实缺陷

**1. 材料匹配错误（严重）**
初版用页面标题模糊匹配材料，实际命中 `v2-15`（30 句、0 题）而不是 `v2-2181`。
→ 改为按 lesson id 精确反查，并新增 `by-lesson` 接口。

**2. 空格被按钮吃掉**
点完「开始卡点练习」按钮后焦点留在按钮上，浏览器把空格当「点击按钮」，
标记永远收不到。
→ 进入练习模式时主动 `blur()`，并放宽按钮判断（cet 自己的按钮不拦）。
