## 3. 材料身份（不新增第二套 ID）

| 概念 | 值 | 说明 |
| --- | --- | --- |
| 底座 lesson id | `v2_lessons.id`（整数） | 页面路由 `/workspace/<id>` 用它 |
| 业务 materialId | 由 `source_url` 派生（如 `cet6-202512-conv2`） | `cet_service._business_id()` |
| 回退 | `v2-<lesson_id>` | 派生不出时用 |
| materialVersion | `sha256-<24hex>` | 由 mediaUrl + segments 计算 |

**级别来自 `v2_lessons.tags`**，认 `cet4`/`cet6`/`四级`/`六级`；否则 `unspecified`（= 待分类）。
**不得**按标题关键词推断级别，不得把 `level=cet4` 直接叫「四级真题」。

新增材料元数据**只用现有列**（`tags` + `title` + `source_url` + `duration`），
不为年份/月份/套次/题型新建表。缺失一律显示「未标注」，不猜。

## 4. 导入契约（P2）

复用现有上传设施，**不新建上传端点**：

1. `POST /api/v2/lessons/media-uploads`（multipart `file`）→ `{upload_id, duration, media_kind, quote}`
2. 校验字幕（前端本地解析 + 后端复核）
3. `POST /api/v2/lessons/start` `{"source_type":"uploaded_media","upload_id":...}`
4. `PATCH /api/v2/lessons/library/{id}` `{"title":..., "tags":["cet4",...]}`
5. 写字幕：`db.replace_v2_subtitle_segments(lesson_id, segments)`
6. 返回 `{lesson, lessonUrl}`

**CET 适配层**新增在 `backend/webapp/services/cet_import.py`（新文件），
不改 `v2_lessons.py` 的既有函数签名。

**字幕格式**：SRT（主）、仓库句子 JSON（兼容）。纯文本 → 只作原文，**不伪造时间戳**。
**校验**：起止非负、end>start、顺序递增、不超音频时长、非空文本；错误逐条返回行号。

**去重**：同一音频 SHA-256 + 同 title → 返回已有材料（`duplicate: true`），不建第二份。
