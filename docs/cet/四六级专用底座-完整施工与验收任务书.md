## 0. 先纠正任务范围

用户最新分工已经明确：

- **本施工任务负责：将 EchoLingo 本身优化成四六级专用的学习底座。** 整理材料入口、精简来源、改造导航和学习页面，保留有用能力，让整个产品使用顺畅。
- **队友负责：听不懂按空格 → 卡点定位 → AI 带练 → 换句检验 → 智能复习。** 本任务只保留接入条件，不重复开发这条链路。
- 用户先沿用 EchoLingo 原来的前端风格，不要求重做视觉设计。
- 当前主场景是四六级听力材料学习。不要扩展成作文批改、翻译训练、口语评分等全科平台。

**这份文档取代此前《并行集中施工指令-2026-11-05.md》对“这个施工者”的开发范围。** 旧 F05/F08、AI 生命周期、换句、十分钟智能复习等属于队友模块或后续集成，不能继续成为本任务主线。已有代码与数据保留，不因为重划分工就删除或回滚队友成果。

你的目标是一次完成本任务内的梳理、实现、自测、真实试用与交付；不要只改标题、修几个接口，或每完成一小块就停下来问用户要不要继续。

## 2. 完工后用户实际怎么用

打开应用 → 选择四级或六级 → 查看已有材料或导入本地材料 → 打开听力学习页 → 播放、逐句回听、变速、切换原文 → 查词并收藏词句 → 返回材料库 → 再次进入恢复学习位置。

这条基础链路必须在**无 AI key、未接队友模块**时独立可用。已有配套原文和时间轴时，不强制转写、翻译、生成大纲或调用模型。用户已有音频，本轮不增加语音模型依赖。

## 3. 功能取舍：按此落实

### 3.1 保留并优化

- 本地音频播放、进度拖动、速度切换、逐句/区间回听及已有循环能力。
- 英文原文、隐藏原文、完整听力稿查看；已有译文可切换，没有译文明确说明。
- 单词查询、CET4/CET6 词表高亮、生词收藏、句子收藏、从收藏回到原材料/原音频。
- 最近学习、搜索筛选、材料管理、学习进度与用户设置恢复。
- 现有 AI 词句解释能力可以复用为学习页内的次级操作；以当前句和材料为上下文，按需触发，无 key 时不阻塞基础学习。不要为本轮重做 AI 问答系统。

### 3.2 改造成四六级入口

- 默认导航围绕“听力材料 / 我的收藏 / 设置”；继续学习放在首页显眼位置。可在现有布局内做等效精简，不增加无必要页面。
- 原“课程”改为适合 CET 的“听力材料”；“阅读”如用于听力稿，则改为“原文”，保留其文本与音频联动能力。
- 原词汇工坊简化为词汇收藏；句子库保留为句子收藏。两者可以共用“我的收藏”，不再发展多个重复复习体系。
- 默认展示 CET4/CET6 相关词表；其他词表不作为当前模式的主选项，保留底层资源和原用户配置，不全局删库。
- 全站面向用户的页面标题、面包屑、按钮、加载态、错误态、空态、帮助与 README 要一致；不能只改首页主标题。

### 3.3 从 CET 模式退出

- YouTube、Bilibili、百度网盘、普通网页文章等来源入口及相应主界面提示。
- 独立的文章/PDF 阅读课程、文本生成朗读课程、泛英语视频学习入口。
- 记忆故事、情境造句、雅思口语复用、自由复述评分及其他与本轮听力底座无关的模块入口。
- 泛用 AI 聊天、大纲生成和不影响基础学习的复杂资源编辑，不再占据核心区域；已有可用词句解释放在上下文中。
- 与实际本地运行模式无关的积分、登录、个人档案等入口只在确认非基础依赖后隐藏；不得为简化 UI 绕过鉴权或改变服务安全配置。

退出是 CET 产品模式内的路由、渲染和初始化收束。优先通过集中功能配置控制，避免散落 CSS 遮挡。未展示的模块不要继续自动发起后台生成/平台探测。底层解析器、共享组件、历史记录、许可与署名保留；无需物理删除所有通用源码。

原链接进入被收束页面时，应跳到合理入口或显示明确说明；不得出现死链接、空白页、隐藏按钮仍可被 Tab 聚焦的情况。

## 4. 必须完整实现的工作包

### P0：基线保护与范围清单

1. 阅读仓库 AGENTS（如有）、CONTRIBUTING、现有数据路径与启动方式。
2. 检查主分支和正在进行的修改，不强制切分支，不覆盖他人更改。为本任务建立独立 `codex/cet-base-*` 分支/工作树。
3. 检查实际页面和功能入口，产出保留/改造/退出清单，标注文件、依赖和负责人；按上述范围直接定案并继续施工，不等用户审批此清单。
4. 隔离测试数据库、配置、产物与端口。共享音频可以只读引用；**不要把多个工作树的可写数据库软链到同一 `.cet-qa/data`**。

### P1：首页与四六级材料库

- 明确四级/六级选择；材料卡片显示级别、名称、时长、素材类别及可用状态。
- 年份、月份、套次、题型等来自已知元数据或用户填写；缺失显示未标注，不猜。年份/题型筛选基于实际存在的数据，空值可正常使用。
- 支持按标题搜索、级别筛选、最近学习、继续学习、修改材料信息、可恢复归档；不要求新增不可逆删除。
- 旧材料无法可靠判断级别时列为“待分类”，提供手动归类；不能按标题关键词自动误认成官方真题，也不能静默丢掉旧材料。
- 空库给一个明确“导入听力材料”入口，不出现满屏占位模块或虚构学习统计。

### P2：普通用户可用的本地导入

- 使用现有上传基础设施，提供简单统一的本地入口：选择音频 → 填写/确认标题、四级/六级、真题/练习/样例及可选来源 → 可选配套原文/字幕 → 校验 → 导入 → 直接打开材料。
- 最低支持现有播放器可用的常见音频格式，界面明确列出实际支持类型；不承诺未测试格式。
- 配套字幕至少支持一种普通用户可准备的带时间轴格式（优先 SRT），兼容仓库现有句子 JSON；纯文本可作为原文导入，但不得伪造逐句时间戳。可下载格式示例。
- 仅音频也能导入和整段播放；无时间轴时明确“暂无逐句定位”，禁用对应操作。没有 key 时不得强制排队转写。
- 字幕检验时间起止、顺序、音频范围、空文本；错误指出具体条目，不能默默跳过损坏行并报全部成功。
- 导入过程有真实状态和失败重试；失败不留下正常可用假卡片；重复提交不产生意外多份，重复素材给用户可理解的处理方式。
- 材料业务身份不依赖硬编码 lesson 数字或本机绝对路径；正常关联既有 lesson ID，不破坏队友已使用的 materialId/version。
- 现有题目与答案资料作为可选附件/既有字段原样保留并在交接文档说明。不新增做题判分、证据诊断、卡点定位算法；这些接入和行为与队友确认后集成。

### P3：听力工作区与收藏

- 沿用现有播放器、布局和视觉，减轻纯音频页面不必要的大块视频占位；不重做设计系统。
- 播放、暂停、拖动、倍速、逐句切换、已有循环、原文显示操作明确；学习页初始状态不能假称“字幕生成中”或“AI 正在分析”。
- 切换材料时音源、标题、原文、当前句和进度必须匹配；不能显示 A 材料而播放 B 音频。
- 刷新和重开页面后恢复该材料的学习位置；完成/已学习状态来自真实行为，不编造掌握度或 CET 预测分数。
- 词典离线或已有本地能力正常使用；收藏词句保留材料身份、原句和已有音频定位信息；移除收藏不删除原材料。
- 收藏返回原文/原声确实跳转，缺少时间轴或音频不可用有明确反馈。
- 全文原文是听力稿辅助，不扩成独立泛阅读产品。没有译文、没有解释时不留下空壳按钮。

### P4：设置、状态、文案与启动交付

- 设置聚焦默认级别、学习显示、实际可用的词表和现有模型设置入口。不要修改用户现有模型、供应商、密钥、网络配置。
- 基础使用不需要 key；保留的 AI 操作有等待、失败和重试反馈，不拖住播放。
- 清理“雅思复用”“粘贴 YouTube 链接”“生成记忆故事”等残余主流程文案，以及指向已退出功能的帮助链接。
- 阅读现有启动脚本后给出可复制启动方法；检测端口占用，不误连其他服务；从空库和已有库均能启动，不硬编码某一工作区 URL。
- README/使用说明写清本版本用途、导入格式、基础功能、队友模块接入状态、实际测试平台；保留上游 LICENSE 和必要归属信息。
- 本轮交付本机可运行源码与演示入口，不擅自扩大为多平台安装包或公开部署；未测平台如实标注。

### P5：队友接入边界

- 不删除或重写 `cet-listening.js`、智能体状态机及其学习记录，除非是本任务造成的兼容回归修复。
- 已有模块可保持原状，但与队友功能交接记录清楚。底座单独运行时不显示无法使用的“开始 AI 带练”等假入口；实际接通才展示。
- 提供独立文档：材料列表/详情、音频地址、句子索引、级别与版本、播放器获取方式、seek/play/pause/倍速、挂载位置、快捷键归属和关键事件。
- 空格标记由队友模块拥有；基础播放器快捷键不得抢占已启用的卡点模式。无需本任务实现回溯和标记策略。
- 核对队友接入关闭/开启两种模式下基础页面均不报错、不重复监听、不重复挂载。开启只做现有接入冒烟，不代替队友完整训练验收。
- 缺少对方代码时，交付真实可用的底座与明确适配契约；可用测试适配器检查接口，但不能把模拟训练包装成已集成。
